# Set operating scope before expanding platform work
**Date**: 2026-10-09 · **Change**: personal-macos-scope · **Category**: process

## What happened
The follow-up list prioritized Windows implementation and Linux benchmarks even
though the owner uses this personal tool exclusively on macOS. Technical backlog
breadth was being mistaken for a required product roadmap.

## How to avoid
Record the actual operating scope in agent guidance and roadmap first. Keep
integrity and existing CI, but reconsider ports only when actual usage changes.
